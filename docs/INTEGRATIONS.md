# Integrations: Meta Ads, website forms, n8n / Make

The CRM receives normalized JSON at:

`POST https://YOUR-CRM-DOMAIN/api/webhook.php`

Authentication header:

`X-CRM-Token: YOUR_LONG_WEBHOOK_SECRET`

Do not place this secret in public website JavaScript. Send submissions through your website's server-side PHP handler or a trusted automation platform.

## Accepted JSON fields

```json
{
  "source": "Meta Ads",
  "external_lead_id": "META_LEAD_ID_123",
  "full_name": "Rahul Patil",
  "phone": "+919876543210",
  "email": "rahul@example.com",
  "project_id": 2,
  "campaign_name": "Pune 2 BHK Leads",
  "adset_name": "Baner 15 km",
  "ad_name": "Premium 2 BHK Video",
  "form_name": "2 BHK Enquiry Form",
  "budget": "75 lakh - 1 crore",
  "preferred_location": "Baner",
  "property_type": "2 BHK",
  "purpose": "Self use",
  "remarks": "Imported from lead form"
}
```

`source` must be `Meta Ads`, `Website`, or `API`. `project_id` must be the numeric ID of a project in the CRM. If project is omitted or has no owner, lead remains unassigned. `external_lead_id` prevents duplicate imports from the same source. The API returns the existing lead ID if the same source + external ID is sent again.

## Website form integration

Recommended flow:

1. Website form collects customer details and includes a hidden project ID (or a server-side mapping from the selected property page).
2. Website backend validates the form and consent.
3. Backend sends JSON to the CRM webhook using cURL and the `X-CRM-Token` header.
4. CRM returns `{ "ok": true, "lead_id": ..., "lead_code": ... }`.

Example server-side PHP request:

```php
<?php
$payload = [
  'source' => 'Website',
  'external_lead_id' => 'website-' . bin2hex(random_bytes(8)),
  'full_name' => $_POST['name'] ?? '',
  'phone' => $_POST['phone'] ?? '',
  'email' => $_POST['email'] ?? '',
  'project_id' => 2,
  'remarks' => 'Website enquiry'
];
$ch = curl_init('https://YOUR-CRM-DOMAIN/api/webhook.php');
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => [
    'Content-Type: application/json',
    'X-CRM-Token: YOUR_LONG_WEBHOOK_SECRET'
  ],
  CURLOPT_POSTFIELDS => json_encode($payload),
  CURLOPT_TIMEOUT => 15
]);
$response = curl_exec($ch);
$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);
// Log failures server-side; never display secret or raw server errors to visitors.
```

## Meta Lead Ads integration (recommended n8n/Make bridge)

Use a trusted server-side automation because Meta lead notifications contain a lead ID; your integration must fetch the full lead details from Meta Graph API using a valid Page access token and required permissions.

Suggested n8n flow:

1. **Facebook Lead Ads Trigger** — connect the correct Meta Business, Page and instant form.
2. **Get lead details** — retrieve name, phone, email and custom form answers from the Meta lead ID. Use the Meta connector/node or Graph API with a server-side Page access token.
3. **Map project** — map the Meta form ID or campaign/ad name to the matching CRM `project_id`. Keep this mapping in n8n or a controlled lookup table. Do not rely on a free-text form answer if you can map by form ID.
4. **HTTP Request** — POST to `/api/webhook.php`, JSON body as in the example above, header `X-CRM-Token` set to the CRM secret.
5. **Error path** — alert the admin if Meta data retrieval or CRM delivery fails; retry transient failures without creating duplicates (send the same `external_lead_id`).
6. Test using Meta's test lead feature and verify that project ownership is correct.

Meta setup checklist:

- Use the correct Meta Business Portfolio, Page and lead form.
- Ensure the connected user/system has the necessary lead access and app permissions.
- Subscribe the integration to the relevant Page leadgen events.
- Keep Page access tokens in n8n credentials/server environment, never in client JavaScript or a public repository.
- Map each lead form to a CRM project ID. If one form serves multiple projects, include a project identifier in the form or split forms by project.
- Periodically verify token validity and lead retrieval permissions.

## n8n HTTP Request node mapping

- Method: `POST`
- URL: `https://YOUR-CRM-DOMAIN/api/webhook.php`
- Send body: JSON
- Header: `Content-Type: application/json`
- Header: `X-CRM-Token: <secret from credential store>`
- Body: map `source`, `external_lead_id`, `full_name`, `phone`, `email`, `project_id`, `campaign_name`, `adset_name`, `ad_name`, and `form_name`.

## Project ID lookup

Project IDs are generated by MySQL when projects are added. In the first release, check IDs in phpMyAdmin's `projects` table. A future release should provide a project integration mapping screen so the team does not need phpMyAdmin.
